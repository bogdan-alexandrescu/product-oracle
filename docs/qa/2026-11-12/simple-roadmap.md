# Simple Roadmap: visual QA findings

**What was checked:** main at e5431e8, the mock build (`npm run build:mock`, `start:mock -p 3393`). Every page was driven with Playwright at 1440 x 900 and 390 x 844 (touch), in light and dark. The mock clock was pinned to Oct 22, 2026. Screenshots are in `shots/`, named `<d|p>-<l|d>-<step>-<state>.png` (d = desktop, p = phone; l = light, d = dark). Downloaded exports are in `shots/*-export*.png|pdf`.

**States covered:**
- Timeline (3 months, 6 months, 1 year, All 3 years), Gantt (grouped by Track, Goal, PRD and Milestone; Day and Week), Now / Next / Later, Waterfall.
- The feature panel opened from each format (top, middle and end), and each "Change" editor opened (Status, Dates, Owner, Goal, Measure, Milestone, Add a dependency).
- Dragging a timeline bar, then Undo. Dragging a board card, then Undo.
- Needs a decision tray: at rest, scrolled, "Accept" on a date (all counts went 23 → 22 at once: button, nav badge, tile, Decisions, Inbox), "Accept as risk".
- Key dates, Removed, Tracks (add a track, change a track), Start review, Quick add.
- New milestone from the board ("+ Milestone", kind, name, save), editing it, opening a timeline milestone.
- PNG and PDF exports of each format.
- The `empty` scenario (all formats) and the `large` scenario. On the roadmap, `large` shows the same data as default.

**Console errors and page errors:** none in any run. **Sideways scroll on phone:** none on any page (`scrollWidth` was checked on every shot).

**Not covered:**
- Phone long-press drag on the board: my script could not reach the card, so it is unverified.
- Adding a milestone from the timeline axis: the "+ Milestone" hint only shows on hover. It was added from the board instead.

**Environment note, not a product bug:** the ✦ glyph (U+2726, "Suggest a feature", "M1 Beta", the panel's menu icon) shows as an empty box because this container has no font with that glyph. It is not reported.

## Design question (not a defect)

- **Milestone codes renumber when a milestone is added.** A new milestone dated Dec 31 took M2, and Faster activation, Grow retention and Keep alerts quiet went from M2/M3/M4 to M3/M4/M5, changing colour with their codes (d-l-41 vs d-l-43). This matches the documented rule (lib/api/mock/roadmap-codes.ts: "codes by date across the read"), so it is not a bug. But a person who said "M2" in a meeting now means another milestone. Stable codes would need an API change. Raised in questions.json.
